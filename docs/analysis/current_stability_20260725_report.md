### 1.2 本次实验**实测**标定（优先于理论）

| 量 | 值 |

| 运行点 mean I | **510.70 A** |

| 0.225 A 绝对误差 | → 允许 \|δΔf\| ≲ **20.2 kHz**（用实测 a，更紧） |

> 结论：闭环噪声预算必须以**物理标定 a** 反传，不能只套 253.87 kHz/A。

### 2.5 与 0.2 / 0.2S 对照（工作点 ~511 A ≈ 17% In）

| 判据 | 限值（约） | 本次 | 结论 |
| --- | ---: | ---: | --- |
| 0.2% 比值差带（相对 mean I） | ±1.02 A | 长时 σ=0.52 A；Allan@10s=0.024 A | 噪声层远满足；长时 σ 约占 0.2% 带的一半 |
| 运行时 σ_Δf median | 0.2S@1%In：57 kHz；实测 a 下 0.225 A：20 kHz | **11.3 kHz**（p95≈24 kHz） | **频率不确定度预算达标** |
| 运行时 median σ_I | — | **0.13 A** | 优于 0.225 A 绝对锚点 |
| 峰峰值 6.75 A | 0.2% 带 ±1.02 A | ptp 超带 | 若作「稳定性」须说明：含慢变，不是瞬时比值差；宜分段/去趋势后评估 |

**解读建议**：

1. **跟踪/读数噪声**（σ_Δf、Allan 短 τ、current_sigma）→ 对 0.2S 频率预算 **充裕**。  
2. **长时样本 std 与 ptp** → 反映源/环境/热慢漂；线性 0.06 A/h 仅解释小部分 ptp，其余为起伏。  
3. 评价计量准确度应另做 **标准电流阶跃/对照**，本文件是 **固定工作点稳定性**，不是全量程比值差试验。

## 3. 结论摘要

1. **参数**：以实测 **a ≈ 1.114×10⁻⁵ A/Hz（89.76 kHz/A）** 和 **Tu≈0.17 s** 为锚；Γ 建议在完整扫频上实测，起点按 **Γ≈2 MHz** 的 README 表缩放；`maximum_delta_f_sigma` 建议从 2 MHz 收到 **100–200 kHz** 量级以贴近 0.2S 预算。  
2. **稳定性实验**：约 **8 h、5.8 Hz、100% 双峰锁定、零失锁**；工作点 **I≈510.7 A**，运行时 **σ_Δf≈11 kHz、σ_I≈0.13 A**，短时 Allan 最优约 **0.023 A**；长时 σ≈0.52 A、ptp≈6.75 A 以慢变为主。  
3. **两份 CSV**：snapshot ≈ session 的早期完整拷贝（略短 + 2 行未锁），分析用 session 即可。
