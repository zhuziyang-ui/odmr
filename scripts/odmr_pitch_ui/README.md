# NV ODMR A/B 俯仰交互仿真

独立 Streamlit 页面：调节 **A / B 俯仰**（及 \(B_0\)、线宽等），实时查看四族 NV 的 **CW ODMR 谱** 与投影表。

## 启动

仓库根目录：

```bat
scripts\start_odmr_pitch_ui.bat
```

或：

```text
python -m streamlit run scripts/odmr_pitch_ui/app.py
```

依赖：

```text
pip install streamlit numpy plotly
```

（matplotlib 非必需；主图均为 Plotly 交互图。）

ODMR 主图为 **Plotly 交互图**：悬停读 f / PL、框选缩放、滚轮缩放、双击复位、底部 rangeslider。

默认浏览器打开 `http://localhost:8501`（与测量控制台 5173 端口分离）。

## 默认物理量（本机实测 + 武汉地磁）

来自 `cw-30/0721_odmr_full` 全谱双峰洛伦兹拟合（I = 15 A，双峰清晰子集）：

| 量 | 默认值 | 说明 |
| --- | ---: | --- |
| **线宽 Γ (FWHM)** | **14 MHz** | 合并中位；f−≈15.4 MHz，f+≈12.6 MHz |
| **B0（线圈）** | **11 mT** | 沿 **+z 竖直向上**；无地磁时 \|B∥\|=B0/√3≈6.4 mT |
| **地磁** | **开** | 武汉 ≈ 30.59°N, 114.31°E |

### 实验室几何

| 项 | 约定 |
| --- | --- |
| Lab 轴 | +x 地理北，+y 东，+z 上 |
| 亥姆霍兹 | \\(\\mathbf B_{\\mathrm{coil}}=(0,0,B_0)\\) |
| 金刚石 | **(100) 面水平**，[100] ∥ +z |
| 地磁 | F≈49800 nT，I≈47°，D≈−5°（主磁场量级，~2025） |

侧栏可关地磁、改 F/I/D、调台架 **yaw**（光学台 +x 相对真北）。  
分析表见 `docs/analysis/odmr_0721_fwhm_fit.csv`。

按 Γ≈14 MHz 的跟踪尺度提示：

| 参数 | 建议量级 |
| --- | ---: |
| 探测偏置 | 1.4–2.8 MHz（0.1–0.2 Γ） |
| 搜索步长 | ≲ 2.8 MHz（Γ/5） |
| 失锁阈值 | ~7–11 MHz（0.5–0.8 Γ） |

## 模型约定

| 项 | 约定 |
| --- | --- |
| 零点 \(A=B=0\) | 四 \(|B_\parallel|\) 相等 \(= B_0/\sqrt{3}\)，谱简并为一对 \(f_\pm\) |
| 场 | 一维亥姆霍兹 \(\mathbf{B}_{\mathrm{lab}}=(0,0,B_0)\) |
| 旋转 | \(R=R_z(\gamma)R_y(\alpha_A)R_x(\beta_B)\)（与 cw-27 StageModel 一致） |
| 共振 | \(f_{\pm,i}=D\pm(\gamma/2\pi)|B_{\parallel,i}|\)，\(D=2870\,\mathrm{MHz}\)，\(\gamma/2\pi=28\,\mathrm{MHz/mT}\) |
| 谱 | 四族等权洛伦兹叠加，默认单族 FWHM = 14 MHz |

机械台架的 A/B **正方向与零点偏移**需实验标定；侧栏可翻转符号。

## 建议操作

1. \(A=B=0\)：应见两个主 dip（合峰，对比度较深）；劈裂约 357 MHz（默认 B0）。
2. 将 **A 调到 ~5°**（默认 Γ=14 MHz、B0=11 mT）：族间分裂通常已可分辨。
3. 把 Γ 临时改成 2 MHz 对比：可看到“理想窄峰”与本机宽峰的差别。
4. 对照「零俯仰参考谱」虚线，观察线形与深度变化。
